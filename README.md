# breast-cancer-risk-prediction
A Machine Learning project predicting breast cancer risk using patient clinical data.
Predictive machine learning pipeline for breast cancer risk assessment. Features data preprocessing, exploratory data analysis (EDA), classification modeling (XGBoost), and model interpretability (SHAP) using Python to identify key clinical risk factors.

 Tech Stack & Tools
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, XGBoost, SHAP, Matplotlib, Seaborn
